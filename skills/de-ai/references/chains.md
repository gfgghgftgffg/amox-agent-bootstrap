# 链与规则参照

来源：`de_ai_pipeline.md` 的实测描述 + 本次改写。数值只有两份文档，方向可信，具体数字不可外推。

## 竞标链

末跳固定 youdao / modernMt / iciba。Reverso 作英文终端会保留欧式学术短语，二测仍标亮，所以只做中转。modernMt 需要 API key（实测 403），已移除。

| # | 英文稿（EN→EN） | 中文稿（ZH→ZH） | 跳数 |
|---|---|---|---|
| A | `EN-iciba-DE → FR-qq → EN-youdao` | `ZH-iciba-DE → FR-qq → ZH-youdao` | 3 |
| B | `EN-qq-JA → DE-iciba → EN-youdao` | `ZH-qq-JA → DE-iciba → ZH-youdao` | 3 |
| C | `EN-iciba-RU → DE-qq → EN-iciba` | `ZH-iciba-RU → DE-qq → ZH-iciba` | 3 |
| D | `EN-reverso-DE → ZH-qq → EN-iciba` | `ZH-reverso-DE → EN-qq → ZH-iciba` | 3 |

中文稿出英文时末跳落 EN，桥接语种取第一个不同于首尾的语言（通常是日语）。

四条链对同一段各产出一个候选，并联选优，不串联。没有第二轮。

## 段落级特征对照

一份历史实测的对照数据（同一文档内「被检测器高亮」与「放行」的段落），英文规则的取值依据。方向可信，绝对值只有一份样本。

| 特征 | 高亮段 | 放行段 | 规则目标 |
|---|---|---|---|
| ≤11 词短句占比 | 7.7% | 15.7% | ≥16% |
| 情态被动率 /句 | 高 51.3% | 基线 | ≤0.08 |
| 句尾分词伴随 /句 | 0.173 | <0.05 | 0 |
| 逗号密度 /句 | 1.55 | 1.11 | ≤1.15 |
| 套路连接词 | 高 30.4% | 基线 | 随机取用 |
| 句间困惑度标准差 | 0.476 | 0.580 | ≥0.55 |
| 与原句 3-gram 重合 | 0.361（未处理） | 0.110（已清零） | <0.22 |

中文侧没有对应实测数据。中文规则是从下列可数特征推出来的：句长集中、标点单一、连接词密度、`的` 字堆叠、虚化动词（进行/实现/具有/起到）、被动（被…所/得到了/受到了）、排比密度、程式化框架（随着…的发展、在…的背景下、综上所述）。

## 打分

**英文**（`EnglishScorer`，GPT-2 + 句式统计）

```
base   = 0.45 - 0.60×短句占比 - 0.25×(句间NLL标准差-0.50)
       + 0.40×均匀长句占比 + 0.35×情态被动率 + 0.25×套话密度
score  = base
       + 0.80×静音分词率
       + 0.35×max(0, The/This 句首占比 − 0.30)
       + 0.50×max(0, 3-gram 重合 − 0.22)
       + 0.20×情态被动率
保真   = GPT-2 末层隐层余弦，阈值 0.99
```

**中文**（`ChineseScorer`，纯统计）

```
base  = 0.40 - 0.50×短句占比 + 0.30×句长超界 + 0.15×逗号密度
        + 0.20×的字密度超界 + 0.25×套话密度 + 0.15×虚化动词率
        + 0.10×被动率 - 0.10×标点多样性
score = base + 0.50×max(0, 3-gram 重合 − 0.22)
保真   = 长度比（中文没有可比对的隐层基准），阈值 0.75
```

分数只用于候选排序和改前改后比较，不代表任何检测器的输出。

## 校验

任一不过则候选作废：

1. 数字集合包含关系
2. 引用编号集合包含关系
3. 大写标识符 / `kms:*` 一类保留
4. 术语表每项出现次数相等（仅目标语为英文时）
5. 长度比：英文 0.70~1.45，中文 0.75~1.40

第 5 条是唯一能发现「翻译接口悄悄截断长句」的检查。
