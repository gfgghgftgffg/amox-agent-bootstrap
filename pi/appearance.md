# Terminal appearance

English | [简体中文](appearance.zh-CN.md)

| Setting | Value / download |
| --- | --- |
| Pi theme | [catppuccin-mocha.json](themes/catppuccin-mocha.json), deployed by bootstrap |
| Terminal theme | **Catppuccin Mocha** — [official terminal ports](https://catppuccin.com/ports/) |
| Font | **Maple Mono NF CN** — [GitHub releases](https://github.com/subframe7536/maple-font/releases/latest), download `MapleMono-NF-CN-unhinted.zip` |
| Background opacity | **95%** (5% transparency; `0.95` on a 0–1 scale) |

The Mocha palette is the same on Windows, macOS and Linux. Users install the font and configure their terminal themselves:

- **Windows:** install the archive's `.ttf` files, then select Maple Mono NF CN in Windows Terminal → Settings → Defaults → Appearance. Import the [Mocha terminal scheme](https://github.com/catppuccin/windows-terminal).
- **macOS:** install the `.ttf` files with Font Book, then select the font and Mocha in the terminal profile.
- **Linux:** use the desktop font manager or user font directory, refresh the font cache if needed, then select the font and Mocha in the terminal.

All font weights and italics in the archive can be installed together. Restart the terminal after installation. Font size and blur are personal choices; blur support depends on the terminal and desktop. Bootstrap does not install fonts or modify terminal profiles.
